# RouletteSphereChaser v2 設計書 — 多塔パーク型ボールコースター

> 承認待ちドラフト。承認後、フェーズ単位で構築→検証を回す。
> v1（現行機）は `SampleScene` にそのまま残し、v2は新シーン `ParkScene` に `ParkBuilder` で構築する。

## 1. コンセプト

- 観賞用の循環型ボールパーク。**メインタワー1基＋サブタワー4基**を長尺レールで接続。
- 規模: 約 6m × 6m × 高さ3m（v1の約10倍の体積）。ボールは現行の径0.1のまま**32球**同時稼働。
- 各ボールは従来どおり番号（0〜99アトラス）・キャラテクスチャ差し替え・1巡ごとのスコア確定・カメラ追従に対応。

## 2. 塔構成（抽選機構 約25基）

| 塔 | テーマ | 機構 |
| --- | --- | --- |
| **A: センタータワー**（メイン） | v1の正統拡大 | 大スパイラル、風車デッキ×2段、フラップゲート×4、大クルーン、ルーレット盤 |
| **B: パチンコ塔** | 釘と盤面 | 垂直ピン盤×2面（同一鉛直面サンドイッチ式）、ステップチャッカー |
| **C: ジグザグ塔** | 折り返しレーン | 同一鉛直面ジグザグ×2系統、3連シーソー |
| **D: クルーン塔** | すり鉢多段 | 大小クルーン2段重ね（各撹拌ローター付き）、スパイラルウィッシングウェル |
| **E: 風車塔** | 回転機構 | 3連風車、振り子ゲート、回転ドラム（横筒） |

- 塔間接続: バンク付きカーブレール×8本。分岐は**固定ペグ／Y字股／通過型ゲート**などの受動・非閉塞型を基本とし、レーンを完全に塞ぐ可動体は使わない。

## 3. 回収・搬送系（v1最大の教訓を反映）

- **広幅回収床**: 全塔の下に共通の傾斜回収床（8°）。排出口は**幅5ボール分（0.5）×2箇所（東西）**の多列口。単列吸い込みは全廃。
- **リフト2基**（東西）: それぞれ独立にボールを頂上へ搬送。1基あたり複数球の同時ライドを許容（現行`BallLift`は既に並列対応）。
- 各排出口前に**撹拌ローター**を標準装備（アーチ崩し）。
- **フェイルセーフ絶対則**: どの機構からこぼれても必ず回収床に落ち、循環が続く。

## 4. 安定稼働のクリアランス基準（d = ボール径 0.1）

| 部位 | 最小値 |
| --- | --- |
| レーン内幅 | 1.6d |
| 縦落下シャフト | 2.0d |
| すり鉢・ドレン開口 | 3.0d ＋ 撹拌ローター |
| 並走壁の隙間 | 1.5d（さもなくば0.5d未満に密閉） |
| 頭上クリアランス | 1.2d |

その他 AGENTS.md 3章の罠リスト（Cylinder=カプセル、sleepThreshold=0、ScoreZone固定側、フラップ内側倒し、Rampレール占有域、同一鉛直面ジグザグ等）を共通ヘルパで強制する。

## 5. スコア設計

- 点数帯: B塔 5–40 / C塔 15–35 / D塔 30–100 / E塔 10–50 / A塔 20–100。全ScoreZoneに点数マーカー必須。
- LapGateは東西排出口の両方に設置（どちらを通っても1巡確定）。

## 6. 構築フェーズ（各フェーズ末にプレイ検証）

1. **基盤**: パーク床・広幅回収床・リフト2基・共通ヘルパ（`ParkBuilder.cs`新規）→ 8球で循環スモーク
2. **Tower A** → 単独検証
3. **Tower B / C** → 16球検証
4. **Tower D / E ＋ 接続レール全開通** → 24球検証
5. **負荷検証**: 32球×10分連続、詰まりゼロ・スコア分布・エラー0を確認
