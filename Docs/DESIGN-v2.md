# RouletteSphereChaser v2 設計書 — 多塔パーク型ボールコースター（縦積み高密度版）

> 改訂2（2026-08-22）: User方針により全体高さを4倍（約14m級）へ拡大し、
> 各塔を「階層スタック」構造にして抽選機構を縦方向に密に詰める。
> フェーズ1（パーク基盤）は実装・検証済み。

## 1. コンセプト

- 観賞用の循環型ボールパーク。**メインタワー1基＋サブタワー4基**、フットプリント約7m×7m、**高さ約14m**。
- ボールは径0.1のまま**32球**同時稼働（番号0〜99アトラス・キャラテクスチャ差し替え・1巡スコア確定・カメラ追従対応）。
- 各塔は**3〜4ステージの縦積み**。ボールはリフトで頂部へ運ばれ、階層を順に降下しながら連続抽選を受ける。

## 2. 塔構成（抽選機構 約25基・縦積み）

| 塔 | 頂部高 | 階層（上→下） |
| --- | --- | --- |
| **A: センタータワー** (0, 0.3) | 12.8m | ①大スパイラル(12.8→10) → ②風車デッキ＋ゲート4基(10→8) → ③大クルーン＋撹拌(8→6) → ④ルーレット盤(6→5)→盆地 |
| **B: パチンコ塔** (-1.8, -1.2) | 10m | ①垂直ピン盤2連段(10→7) → ②ステップチャッカー(7→5.5)→盆地 |
| **C: ジグザグ塔** (1.8, -1.8) | 10m | ①同一鉛直面ジグザグ6段(10→6.5) → ②3連シーソー(6.5→5.5)→盆地 |
| **D: クルーン塔** (-1.8, 1.8) | 8m | ①クルーン3段重ね(8→5) → ②ウィッシングウェル(5→4)→盆地 |
| **E: 風車塔** (1.8, 1.8) | 8m | ①3連風車(8→6) → ②振り子ゲート＋回転ドラム(6→4.5)→盆地 |

- **塔間接続レール**: 上層帯（約10m）と中層帯（約6m）の2層に計8本。塔の途中階から隣の塔へ分岐する受動分岐（固定ペグ／Y字股。レーンを塞ぐ可動体は禁止）。
- 各階層の「こぼれ」はすべて盆地に落ちて循環継続（フェイルセーフ絶対則）。

## 3. 回収・搬送系（フェーズ1で実装・検証済み）

- 傾斜回収盆地（r2.9・4°・外周壁の谷で自然集約・高壁1.0m）→ 幅1.0の排水口 → 浅テーパー＋撹拌ローター → 2レーン分割 → **リフト2基（頂部14m・速度3.5）**。
- LiftN → タワーA頂部(12.8m)、LiftS → タワーB/C頂部(10m)へ投下。D/E塔はB/C・Aの途中階から接続レールで給球（不足なら第3リフト増設）。
- 8球スモークで68周（3.4m版）・53周/130s（14m版）詰まりゼロを確認済み。

## 4. 安定稼働のクリアランス基準（d = ボール径 0.1）

| 部位 | 最小値 |
| --- | --- |
| レーン内幅 | 1.6d |
| 縦落下シャフト | 2.0d |
| すり鉢・ドレン開口 | 3.0d ＋ 撹拌ローター |
| 並走壁の隙間 | 1.5d（さもなくば0.5d未満に密閉） |
| 頭上クリアランス | 1.2d |
| 高所からの自由落下受け | 受け皿＋高壁（バウンド höhe = 落差×4%を封じ込める） |

AGENTS.md 3章の罠リスト全項目を `GreyboxKit` が強制（Cylinder凸メッシュ・トリガー・点数マーカー・撹拌ローター等）。

## 5. スコア設計

- 点数帯: B塔 5–40 / C塔 15–35 / D塔 30–100 / E塔 10–50 / A塔 20–100。縦積みで**1降下=複数段抽選**になるため、段が下がるほど高配点。
- LapGateは排水路（両レーン共通）に設置済み。
